モバイル向けhosts

オフラインで作成・使用しているものですが、バックアップも兼ねてここに置いときます。
各所のソースでブロックしきれない部分を補うためのものなので単体では使い物になりません。
自己責任でご自由に使用してください。

作成者の使用環境
・Android Chrome
Ad-Shield導入サイトはChromeのサイト別設定でJavaScriptを拒否にしております。例：blog.livedoor.com
・U-フレットなどのJavaScriptをオフにするとまともに閲覧できないサイトを閲覧する際にBraveブラウザを利用

作成者の併用しているソース
・NMTV hosts
・Primary Block Lists : Redirect / github
・hosts2ch 2nd season
・悪いインターネット 0.0.0.0
・ログロイド block
・ログロイド allow

Ad-Shieldは完全にブロックする方針なので、当ホストを利用する方でUフレットなどを閲覧する方はBraveブラウザなどを利用をお勧め致します。
